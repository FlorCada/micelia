# Micelia

Mural de Propuesta de Valor del equipo Micelia para **Molinos Innova 2026** (Entregable 1), en formato página web con scroll.

Biofábrica circular que cultiva gírgolas sobre afrechillo de trigo y aprovecha cada etapa del proceso para generar alimentos, mejorar suelos y desarrollar biomateriales.

## Contenido

- `index.html`: la página completa. Estilos, animaciones, logo y fotos están incluidos dentro del archivo.
- `favicon.svg`: ícono de la pestaña del navegador.
- `vercel.json`: configuración mínima para Vercel.

## Publicar en Vercel

1. Subir esta carpeta a un repositorio de GitHub.
2. En vercel.com: **Add New → Project**, importar el repositorio.
3. Framework Preset: **Other**. No hace falta comando de build.
4. **Deploy**.

## Ver localmente

Abrir `index.html` en el navegador.

## Grabar el video

Abajo a la derecha está el botón **Recorrido automático** (1:30, 2:30 o 3:30). Baja solo por toda la página; se frena con Esc o con la rueda del mouse.
